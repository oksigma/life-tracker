# Frontend (Next.js)

- `src/app/` — routes (App Router): one route per life area, plus `dashboard` and `settings`
- `src/features/<area>/` — components, hooks and logic for each life area
- `src/components/ui/` — reusable UI primitives (buttons, inputs, cards)
- `src/components/layout/` — nav, sidebar, page shells
- `src/lib/` — API client and utilities
- `src/hooks/` — shared React hooks
