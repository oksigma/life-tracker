# LifeTracker

An app that keeps a personal record of different parts of your life: clothing worn, health, movies seen, food eaten and drinks.

This top-level folder holds **documentation and planning only**. All code lives in [`life-tracker-app/`](life-tracker-app/).

| Folder | Purpose |
|---|---|
| `life-tracker-app/` | All application code (frontend, backend, database, infra) |
| `docs/product/` | Vision, feature list, roadmap |
| `docs/specs/` | Feature specifications (written before code) |
| `docs/architecture/` | System overview and architecture decision records (ADRs) |
| `docs/design/` | Wireframes, branding, UI notes |
| `docs/research/` | User research, competitor notes |
| `docs/meeting-notes/` | Meeting notes, dated `YYYY-MM-DD-topic.md` |
