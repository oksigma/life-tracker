# Feature Areas

Each life area is a self-contained module in both the frontend and backend.

| Area | Example tracking | MVP? |
|---|---|---|
| Clothing | Photo of what I'm wearing, logged against the day worn | Yes |
| Health | Weight, sleep, symptoms / how I feel (optional photo) | Next |
| Movies | Movies seen, date, rating, where watched, notes | Yes (first) |
| Food | Meals with optional photo; foods with estimated calories (Open Food Facts or manual); daily totals | Yes |
| Drinks | Drinks had, quantity, time | |
| Exercise | Workouts, duration, estimated calories burned (separate area) | Next |

## Cross-cutting features
- User accounts and authentication
- Dashboard (today / this week across all areas)
- Search and history
- Insights and trends (e.g. most-worn clothes, favourite movies, eating patterns)
- Data export
